# Portfólio Pessoal - Atividade Prática

Este projeto foi desenvolvido para a disciplina de Fundamentos da Programação Web.

## Tecnologias
- HTML5
- CSS3 (sem frameworks)
- JavaScript (sem frameworks)

## Estrutura
- index.html
- style.css
- script.js

## Requisitos atendidos
- Menu visível e funcional em todas as seções
- 4 seções obrigatórias:
  - Sobre mim
  - Formação
  - Portfólio
  - Contato
- Formulário com validação obrigatória de nome, e-mail e mensagem
- Verificação de formato de e-mail
- Simulação de envio com limpeza dos campos e mensagem de sucesso
- Interação adicional:
  - Menu responsivo em dispositivos móveis
  - Alternância de tema claro/escuro com persistência em localStorage

## Publicação no GitHub Pages
1. Crie um repositório público no GitHub.
2. Nome recomendado (exemplo):
   - matamosquito-lanes
   - portfolio-rodrigo-wecoski
3. Envie os arquivos do projeto para a branch main.
4. No GitHub, acesse Settings > Pages.
5. Em Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: / (root)
6. Salve e aguarde a geração do link.
7. URL final esperada (exemplo):
   - https://seuusuario.github.io/portfolio-rodrigo-wecoski/

## Checklist final antes da entrega
- Repositório está público
- Site abre no link do GitHub Pages
- Todos os links do menu funcionam
- Formulário valida corretamente
- Endereço do site não contém localhost nem 127.0.0.1
- Prints com URL visível na barra do navegador

## PDF de entrega (AVA)
Inclua no PDF:
1. Link do site publicado
2. Link do repositório GitHub público
3. Print da estrutura de pastas do projeto
4. Prints das 4 seções no navegador (com URL visível)
5. Código-fonte completo no PDF apenas se não conseguir publicar
